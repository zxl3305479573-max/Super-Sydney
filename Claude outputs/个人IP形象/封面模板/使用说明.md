# 小红书封面模板

尺寸 1080×1440（3:4）。角色是透明底素材，标题用真实字体排版：换标题不用重新生图，中文也不会乱码。

## 出图

1. 编辑 `封面列表.json`，每一项是一张封面。
2. 运行：

```bash
node 生成封面.mjs
```

3. 图片和对应的 HTML 都在 `输出/` 里。

## 三种模板

| template | 适合 | 可填字段 |
|---|---|---|
| `tutorial` | 工作流实操、教程 | title、sub、tag、steps（最多 5 步） |
| `list` | 收藏型清单 | number、unit、title、sub、sticker |
| `recap` | 真实复盘、AI 员工日常 | title、sub、tag、bubble（气泡台词） |

## 标题写法

- `【】` 包住的字加荧光笔高亮，例如 `第一个月【赚了多少】`。
- `|` 手动换行，例如 `我开了一家|只有我一个人的公司`。
- 字号会按最长一行自动缩小，保证不出版心；想固定字号就加 `"size": 100`。
- 建议每行 4 到 9 个字，两到三行最醒目。

## 素材

`assets/` 里是雪梨的透明底素材（打字、指向、团队）和头像。要新增动作，用 `设定稿/0-主视觉-雪梨和AI员工.png` 当参考图生成白底图，再抠成透明底放进来。
