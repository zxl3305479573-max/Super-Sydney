# 雪梨的一人公司 · 形象设定

## 主角：雪梨（老板）
- **外形**：Q 版大头小身；棕色碎发、黑色圆框眼镜；淡黄绿色梨子卫衣，帽顶有棕色梨柄和一片绿叶；藏青头戴耳机挂在脖子上；藏青宽松裤，米白配绿色的运动鞋。
- **性格**：认真、有点较真，偶尔吐槽；是「正在做的同行人」，不是大神。
- **口头禅**：「这段我改一下」
- **固定道具**：笔记本电脑（盖子上是小叶子贴纸）、印着梨子的咖啡杯。

## AI 员工（4 位）
统一外形：奶白色圆头盔，深色屏幕脸配绿色发光眼睛，头顶一根爱心形绿芽天线，绿色点缀，藏青短裤。

| 岗位 | 道具 | 负责 |
|---|---|---|
| 写手 | 大铅笔 + 便签本 | 选题、正文、标题 |
| 画师 | 绿色贝雷帽 + 画笔调色盘 | 封面、配图 |
| 剪辑 | 场记板 | 口播、字幕、成片 |
| 运营 | 大喇叭 | 发布、数据复盘 |

名字待定。

## 配色
| 用途 | 颜色 |
|---|---|
| 主色 | 梨黄绿（卫衣） |
| 辅色 | 藏青（耳机、裤子） |
| 点缀 | 叶子绿、梨柄棕 |
| 底色 | 奶白 |

## 使用规则
- 画风统一：日系 Q 版贴纸风，干净描边，柔和平涂，白底。
- **不出现任何真实品牌 logo**：苹果、星巴克这类都不行，设备一律无标或用小叶子。
- 生成新图时，把 `0-主视觉-雪梨和AI员工.png` 当参考图传给图片模型的 edits 接口，再在提示词里描述动作和场景，角色就不会走样。
