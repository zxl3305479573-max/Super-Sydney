# 视频模块（短视频创作流水线）设计

## 目标

在 Sydney 桌面端的「内容」分组里，给公众号之外加第二条内容流水线：把一条中老年健康科普短视频从选题推进到可交付的制作包。用户能看到每一步的状态，模型只写脚本和分镜，成片由人按制作包完成。

## 定位与边界

- 复用公众号已有的账号表达配置与内容 API 开关（`~/.wewrite/config.yaml` 的 `writer`、`style.yaml` 与设置页的模型调用开关）。关掉开关时两条流水线一起停，避免「公众号里关了，视频还在偷偷花钱」。
- 不引入外部视频引擎：模块不渲染、不配音、不剪辑，也不上传或发布到任何平台。产出物是剪辑时真正要用的文件，成片与发布都由人完成。
- 健康合规规则与公众号一致（不诊断、不开药方、不给剂量、不编造来源），并在每次模型调用时随系统提示一起下发。

## 流水线（6 步）

1. **选题**：平台、标题、目标时长、受众、方向。可让模型给 5 个候选。
2. **口播脚本**：模型按目标时长生成（中文口播约每秒 4 字），可直接编辑。
3. **分镜**：模型把脚本拆成 4-12 个镜头，含画面、口播、字幕与秒数。
4. **字幕**：由分镜秒数累加生成 SRT，纯本地计算，不回模型、不额外花钱。
5. **封面**：竖版 9:16，可选本地图片或 AI 生成（复用公众号的图片接口，尺寸改为竖版）。
6. **制作包**：导出到知识库 `07-视频/<时间戳>-<id>-<随机串>-<标题>/`。

## 产物与门槛

制作包目录包含四样东西：

- `制作包.md`：frontmatter、口播脚本、分镜表、交接说明与合规声明；
- `shotlist.csv`：镜号、时长、画面、口播、字幕，供剪辑软件导入；
- `captions.srt`：字幕；
- `cover.<ext>`：封面（设置了才有）。

导出的硬门槛只有两条：口播脚本非空、分镜至少一个镜头。封面是可选项，缺失时制作包里不含封面图，但发布到平台前通常需要人工补。

## 状态与失效规则

- 状态取值 `idea → script → storyboard → exported`，表示「已经确认到哪一步」。
- 改标题、换平台、选封面不影响已有产物，状态不动。
- 改脚本会把状态退回 `script`：分镜标成「需处理（脚本在分镜之后又改过）」，导出的制作包标成「需要重新导出」。
- 重写分镜把状态推回 `storyboard`，清空分镜退回 `script`。
- 手改分镜 JSON 时，非空内容解析不出镜头就当场拒绝保存，不把分镜静默清空。

## 模块边界

- `desktop/services/video-pipeline.ts`：纯函数规则层——镜头解析与归一化、SRT 时间轴、时长核算、6 步状态推导、导出门槛、编辑补丁（含失效规则）。
- `desktop/services/video-workflow.ts`：只负责选题、脚本、分镜三次模型调用与结果校验。
- `desktop/services/video-export.ts`：制作包落盘（Markdown / CSV / SRT / 封面）。
- `desktop/shared.ts`：`VideoProject`、`VideoShot`、`VideoStage`、`VideoAssetBundle` 与 `SydneyApi` 的视频方法。
- `desktop/main.ts`：`video_projects` 表与 `video:*` IPC；封面复用现有图片接口，导出写知识库。
- `desktop/renderer/VideoPanel.tsx`：沿用公众号的 `.flow-*` 流水线骨架（步骤条、面板、看板进度条），只补竖版封面预览与字幕预览两处样式。

## 错误处理

- 未开启内容 API 开关：生成按钮报「请先在公众号配置中允许内容 API 调用」，不发起请求。
- 模型返回非法 JSON / 空选题 / 无有效镜头：报错并保留上一步已有产物，不回滚。
- 同一任务并发操作：按任务加锁，提示「正在处理，请等待当前操作完成」。
- 导出时封面文件不存在：报错并清理本次新建的制作包目录，不留半个包。
- 重复导出：目录名带时间戳与随机串，永不覆盖上一次的包。

## 测试和验收

- `desktop/test/video-pipeline.test.ts`：步骤状态推进、失效规则、镜头解析容错、SRT 时间轴、时长偏差、导出门槛、编辑补丁。
- `desktop/test/video-workflow.test.ts`：三个阶段的提示词内容（含平台指南与合规规则）、结果校验、缺 key 与 HTTP 错误。
- `desktop/test/video-export.test.ts`：制作包四件产物、CSV 转义、SRT 内容、重复导出不覆盖、缺封面时清理目录。
- `npm test`、`npm run typecheck`、`npm run build` 通过。

## 不在本次范围

- 视频渲染、配音、字幕烧录与自动剪辑。
- 上传或发布到抖音 / 视频号 / 小红书 / B 站。
- 多语言、多账号与素材库管理。
- 文章一键转视频（复用公众号成稿做输入）。
