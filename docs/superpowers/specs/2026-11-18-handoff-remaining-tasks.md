# Sydney 视频与运营工作台后续交接任务清单 (Handoff & Remaining Roadmap)

> **创建日期**：2026-11-18  
> **适用版本**：Sydney v0.1.8+  
> **面向对象**：后续接手开发、测试与迭代的 AI Agent 及工程师

---

## 一、当前已完成的核心闭环（v0.1.8 状态）

1. **视频工作台 2.0（全链路闭环）**：
   - **双页签架构与保活**：`视频制作` 与 `多平台分发` 拆为顶层页签，采用 KeepAlive 保活机制，切走不丢失草稿与状态；新建路线解耦，支持项目删除与未保存修改弹窗拦截。
   - **前置创作能力补齐**：红狐热点/联网检索、5 候选选题、结构与要求配置、分镜增删改移与运镜音效标记、TTS 引擎试听（带 Electron 系统代理）、3 套真实配色（深色底 >10% 亮度避开 ffmpeg blackdetect 误报）。
   - **成片与本地封面**：修复连续静帧合并提升 5~10 倍合成速度，修复 BGM ducking `asplit=2` 混音报错，引入 `sydney-video://` 流式预览与 `video-local-cover.ts` 0 成本大字/IP 主封面生成器。
   - **多平台差异化交付**：抖音/视频号/小红书/B站四平台独立参数包，B 站 00:00 分镜章节切分，视频号 6-16 字短标题与 mp4 faststart 二进制头校验，FFmpeg 高斯模糊多比例封面（3:4 / 4:3 / 16:9 / 9:16）。

2. **运营中控（OpsHub）**：
   - 创作者后台 WebContentsView 只读同步粉丝增量与作品播放数据，遵守「遇登录墙/验证即停、不自动滚屏、不逆向接口」原则。
   - 作品第 1/3/7 天同龄指标对比复盘，飞书彩色卡片 Webhook 自动化汇报。

3. **发版与更新系统标准收敛**：
   - 彻底清除更新说明中的 `<>` 尖括号，防止旧版本客户端渲染出 `<h3><ul><li><code>` 原始标签。
   - 更新说明严格按 `【新增功能】`、`【优化内容】`、`【修复 Bug】` 三类组织。
   - 发版脚本自动向 `latest.yml` 注入纯文本 `releaseNotes: |-`，新版更新弹窗以分类药丸徽章（tone-add / tone-opt / tone-fix）高亮展示。

## 二、未完成 / 后续规划任务清单（待后续 Agent 继续执行）

### 优先级 P1：多平台分发与平台 DOM 适配跟进
- [ ] **视频号助手合集与活动标签联动**：
  - *当前状态*：目前分发仅支持基础短标题（6-16字）、正文、封面与本地视频上传。
  - *后续任务*：针对拥有系列视频的用户，在发布抽屉中增加「合集选择」或「活动标签」，并在已渲染 DOM 中匹配视频号助手的合集下拉组件。
- [ ] **平台表单变更防脆性加固**：
  - *目标*：国内四平台（抖音、小红书、微信视频号、B站）网页版会不定期改版 DOM 类名。
  - *策略*：继续恪守「安全辅助填表，绝不帮用户点最终发布」底线；当选择器未命中时，在界面提示「平台页面结构微调，请手动点击粘贴对应字段」，绝不阻断流程。

### 优先级 P2：视频制作体验进阶
- [ ] **时间轴多轨音频与波形可视化预览**：
  - *当前状态*：旁白配音与背景音乐通过 FFmpeg 滤镜在后台合成并自动闪避（ducking）。
  - *后续任务*：在「视频制作」的「配音与字幕」步骤中，引入轻量级 Canvas 音频波形预览，允许创作者更直观地拖拽调整背景音乐在不同分镜的底噪比例。
- [ ] **本地大字封面支持自定义背景图导入**：
  - *当前状态*：`video-local-cover.ts` 使用高斯渐变色块 + 重点标题 + IP 角色透明底形象。
  - *后续任务*：在 `VideoLocalCoverInput` 中扩展 `customBgImageBuffer` 字段，允许创作者上传专属底图，由 sharp 自动缩放裁剪并叠加品牌大字与 IP 人物。
- [ ] **更丰富的视频排版视觉模版**：
  - *当前状态*：提供 `warm`, `clean`, `night` 3 套经典配色。
  - *后续任务*：可增加更多风格模版（如科技青蓝、复古暖棕、极简白灰），并在 `FRAME_TEMPLATE_VERSION` 升级时同步验证。

### 优先级 P3：运营中控与复盘分析拓展
- [ ] **更多企业通知机器人适配（企业微信 / 钉钉）**：
  - *当前状态*：已支持飞书群机器人彩色卡片通知（`services/ops-hub.ts`）。
  - *后续任务*：参考飞书实现，抽象出 `NotifierService`，增加企业微信与钉钉 Webhook 适配，密钥通过 `secret-store` 加密保存为 `wechat-work-webhook.bin` / `dingtalk-webhook.bin`。
- [ ] **作品生命周期多期对比折线图**：
  - *当前状态*：中控面板以表格与对比倍数展示第 1/3/7 天指标。
  - *后续任务*：在前端增加轻量 SVG 曲线图，直观展现多期视频在发布 24h 内的播放爬坡轨迹。

## 三、重要架构规范与防坑备忘（开发必读）

1. **更新日志与发版规范（严格执行）**：
   - 每次发版**必须**更新 `CHANGELOG.md`，必须分为 `### 新增功能`、`### 优化内容`、`### 修复 Bug` 三大类，且**正文中严禁出现尖括号 `<>`**。
   - 发版自动通过 `scripts/release-notes.mjs $version --inject-yml release/latest.yml` 注入纯文本。
2. **Windows 与 PowerShell 环境要求**：
   - 控制台执行命令切勿使用 `&&` 连接（PowerShell 不支持），必须分行或用 `;` 分隔。
   - 发起境外或代理接口请求时，务必走 Electron `net.fetch`（跟随系统代理设置），切勿直接使用 Node 全局 `fetch`。
3. **保持测试驱动（TDD）**：
   - 核心改动后运行 `npm run typecheck` 与 `npm test`。
   - 所有 IPC 通信改动需同步更新 `desktop/test/ipc-contract.test.ts`。
